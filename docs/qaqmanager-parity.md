# QAQManager 4.7.8 交互对照

对照终末地的本地管理流程，记录 QAQManager 的可达操作、Endfield Mod Manager 第一版已有功能，以及值得进一步核对的差异。参考安装目录为 `D:\MOD\QAQManagerV4`，Mod 库为 `D:\MOD\XXMI\EFMI\Mods`。

## 依据与验证范围

- **实机观察**涵盖角色首页、Mod 列表和画廊切换、外观分区的中英文名称与封面表单、预设卡和新建快照表单、系统设置中的路径和更新区、五步安装向导的 XXMI/NEMI 入口，以及个性化的会员提示。实机检查停在表单或取消，未对实际 Mod 库执行安装、启停或删除。
- **静态核对**读取已安装版 `resources/app.asar` 中的版本信息与渲染层事件处理器，以及 `resources/overlay.html` 和 `resources/side-panel.html`。下文其余旧版路径以此为依据。涉及安装、覆盖、回收站、修复、游戏 F10 的结果仍需在对应环境验证。
- 已安装版的 `resources/app-update.yml` 将 GitHub 更新源指向 `peterdua/QAQmod-Client`，该地址对未登录访问返回 404。公开的 `peterdua/qaqmanager-releases` 根目录只有 README，4.7.8 发布页提供 Windows 安装包。本次静态对照使用本地已安装资源。 [公开发布仓库](https://github.com/peterdua/qaqmanager-releases) · [4.7.8 发布页](https://github.com/peterdua/qaqmanager-releases/releases/tag/v4.7.8) · [作者站点](https://www.qaqm.top/)

## 预设页

QAQManager 的「新建预设」在页内展开表单，输入名称和可选备注后捕获当时全部已启用的 Mod。点预设标题展开，以角色分组查看包含的 Mod。独立的「应用」按钮切换磁盘状态，结果展示启用、禁用和缺失数量。展开普通预设可立即用当前状态覆盖内容、内联编辑名称和备注，或在确认后删除。内置纯净预设只提供应用，用于关闭所有 Mod。导入和导出走系统文件选择器。

第一版已提供快照、JSON 导入导出、内置纯净预设和应用结果。可视化编辑器可搜索并勾选指定 Mod，也能显示磁盘上缺失的条目。应用前的 RabbitFX 警告和会话内多步撤销是新增的本地能力。复查快照覆盖、展开收起、编辑取消、删除确认和应用失败后，列表内容及「当前应用」标记应与实际目录状态一致。

## Mod 导入和修复的分支

1. **选择来源**。旧版角色总览有批量文件夹入口与整合包说明，角色页可将安装目标锁定到当前角色。普通压缩包、文件夹、MP4 会进入识别或解包步骤；管理员模式下另有手动选择入口。某些旧版入口提示先用外部工具解开大包。
2. **核对候选**。旧版按来源层级展示单个 Mod、多个 Mod、整合包。识别到 XXMI/EFMI 更新或修复器时，进入安装方式和目标确认；整合包覆盖当前 Mods 是独立选项。普通 Mod 可改名及改目标角色，未匹配的条目可手动选择目标。
3. **执行和结果**。旧版显示解包和安装进度、逐项成功或失败，以及最终摘要。第一版已有暂存分析、角色和外观分区选择、跳过项、EFF 警告及逐项结果。重名采用新目录名，整合包拆分成候选项。普通导入、安装环境更新和执行自定义修复器在第一版使用各自的入口。
4. **修复和恢复**。全库、角色和单项 Mod 是不同范围。旧版结果弹窗提供故障处理线索，单项右键可继续回滚。第一版使用时间戳备份并显示可回滚记录。常规验证可用临时库，检查失败是否报告、取消是否清理暂存，以及回滚是否恢复选中批次的文件。

## 局内浮窗与侧窗

- 旧版用全局热键呼出，默认 `Alt+F`。主窗可固定、缩放和复位，横向角色条通过滚轮切换角色或打开头像气泡侧窗。Mod 支持列表和画廊、排序、定位、单选和合集。预设在同窗中选择应用。
- 点击 Mod 打开侧窗详情。角色气泡和详情共用侧窗，侧窗有独立宽度按钮与关闭入口。详情可以启停 Mod；允许转发时可以点按 Mod 快捷键。旧版浮窗的 Esc 优先处理打开的菜单或设置；侧窗有自己的 Esc 关闭逻辑。
- Mod 右键可打开源目录、返回管理器并定位、置顶、标记、修复或重置 INI。角色右键可恢复该分类下的 INI。浮窗内设置提供背景透明度、热键录制、独立的 Mod 自动重载、预设自动重载、快捷键点击开关，以及 Persist Bridge 缓存设置。
- 新版有双窗贴边、自适应摆放、全局呼出、预设应用和 F10 等操作，也有独立的重载和点击转发选项。补齐了启用项定位、合集变体、Esc 层级、RabbitFX 替换确认、呼出键录制和缓存槽数设置。新组合无法注册时保留原热键。UAC 权限对齐、F10 和带修饰键的快捷键转发需要在游戏运行时验证。

## 本轮新增的行为与验证

- 角色一览支持按内容筛选和三种排序。自定义排序保留隐藏项的位置。把图片拖到已有角色卡片上会进入封面裁剪。
- 角色内支持可持久化的列表、画廊、外观分区和排序偏好。调整分区后会跳到目标条目，详情可以收起和调宽，预览接收图片拖放和剪贴板图片。嵌套弹窗按最上层处理 Esc，并在关闭后尽量恢复焦点。
- Mod 开关、预设与撤销会预检目录移动，并在中途失败时尝试回滚已移动的目录。撤销记录绑定原 Mods 目录，预设的应用标记按当前磁盘的启用集合计算。
- 整合包支持外层目录和逐项添加，并保留源 Mod 的 `DISABLED_` 状态。安装在同盘暂存目录复制完整后再改名就位，重名追加编号。旧版整体覆盖现有 Mods 的分支未移植。
- 初始化向导使用只读草稿校验，保存后显示配置摘要。更新压缩包或文件夹前明确选择来源和目的地，拒绝互相包含的更新目录。
- 便携版和 `EFMM_DATA_DIR` 下的 WebView2 数据与配置使用同一数据根，解决隔离运行时创建默认目录失败的问题。窗口创建移出 Windows UI 回调线程，防止首次呼出浮窗卡住。主窗口设为直接退出时，已打开过的浮窗不会让进程留在后台。
- 新版通过前端构建和 32 项 Rust 测试。Windows 使用独立的三项 Mod 测试库验证了启动与退出、角色筛选、列表与画廊、详情定位、灯箱和分区裁剪的 Esc 行为、向导保存与导入入口，以及浮窗定位和侧窗关闭。实机录制和启用了新热键，修改的缓存槽数也写入隔离配置。旧版占用 `Alt+F` 时，注册返回错误，已生效的热键仍可切换浮窗。实测未运行游戏，也未修改真实 Mod 库。

## 按本地工具的目标取舍

- 删除「支持主包」、账号、赞助者墙、兑换码和评论资料。保留本地更换背景、模糊和遮罩，扩展为本地主题和图片列表。
- 移除 QAQManager 配置和预设迁移，保留本软件的 JSON 导入、导出。Persist Bridge 使用独立的 `EFMI\efmm\` 目录、`EFMM\Persist\` 命名空间和 `.efmm-persistbak` 备份。若旧桥接仍在挂载状态或有 Mod 尚未还原，应用会给出提示。
- 默认主题调为浅粉，图标采用提弗洛斯。角色页将导入、修复、刷新等操作放在「更多操作」菜单，排序和分区使用主题下拉菜单。列表和画廊共用详情宽度，默认占可用宽度 40%，拖动分隔线后自动保存。收起和展开详情时，面板宽度随动画变化。
- 市场、发布、云端下载、在线 AI 标签、开发者加密导出和多游戏分支超出本次终末地本地复刻范围。旧版内置第三方封面、安装包和修复器的分发也需要单独核实来源及授权。
- 旧版 Mod 视图包中存在批量全选、开启、关闭和删除的处理函数，其模式开关只有关闭调用。批量操作归入可选的新功能。
